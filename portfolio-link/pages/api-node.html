API de capteurs en Node.js

API REST avec base de données et authentification par jeton.

Le même service que l'API Python, reconstruit en Node.js avec une vraie persistance : les mesures sont stockées dans une base SQLite.

La lecture est publique. L'ajout d'une mesure exige un jeton JWT, obtenu à la connexion puis transmis dans l'en-tête Authorization.

Node.js, Express, better-sqlite3, jsonwebtoken. Code source sur GitHub
