Basket 2D

Jeu d'arcade de basket à deux joueurs, dans le navigateur.

Écrit en JavaScript pur sur Canvas HTML5, sans aucune dépendance. Deux joueurs s'affrontent sur le même clavier pendant deux minutes.

Dribble animé pendant les déplacements, dunk près du panier, contre possible, traînée visuelle pendant le tir et écran de fin avec le score.

JavaScript, Canvas HTML5. Personnages : Kenney (CC0). Ballon : OpenGameArt (domaine public). Code source sur GitHub
