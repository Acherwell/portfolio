Monitoring de capteurs

Système embarqué simulé : collecte, alertes et tableau de bord web en temps réel.

Ce projet simule un système embarqué de type Raspberry Pi. Des capteurs de température et d'humidité produisent des mesures, enregistrées automatiquement dans un fichier CSV.

Une interface web affiche les données en temps réel, avec un rafraîchissement toutes les 3 secondes et une page dédiée aux alertes. La collecte et le serveur web tournent en parallèle, dans deux fils d'exécution.

Python 3.12, Flask, threading, CSV. Code source sur GitHub
